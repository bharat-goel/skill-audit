**`formatRelativeTime.ts`**
```ts
const MONTHS = [
  "Jan", "Feb", "Mar", "Apr", "May", "Jun",
  "Jul", "Aug", "Sep", "Oct", "Nov", "Dec",
];

export function formatRelativeTime(iso: string, now: Date = new Date()): string {
  const then = new Date(iso);
  const diffSec = Math.floor((now.getTime() - then.getTime()) / 1000);

  if (diffSec < 60) return "just now";

  const diffMin = Math.floor(diffSec / 60);
  if (diffMin < 60) return `${diffMin}m ago`;

  const diffHour = Math.floor(diffMin / 60);
  if (diffHour < 24) return `${diffHour}h ago`;
  if (diffHour < 48) return "yesterday";

  const diffDay = Math.floor(diffHour / 24);
  if (diffDay <= 7) return `${diffDay}d ago`;

  return `${MONTHS[then.getMonth()]} ${then.getDate()}`;
}
```

**`formatRelativeTime.test.ts`** (Jest) — 4 tests covering the 60s, 60m, 24h, 48h, and 7-day boundaries.

Boundary behavior, traced by hand:
- 59s → `just now`; 60s → `1m ago`; 59m → `59m ago`
- 23h59m59s → `23h ago`; exactly 24h → `yesterday`
- exactly 48h → `2d ago`; exactly 7d → `7d ago`; 8d → falls to date format (`Mar 2` for a 2024-03-10 `now`)
