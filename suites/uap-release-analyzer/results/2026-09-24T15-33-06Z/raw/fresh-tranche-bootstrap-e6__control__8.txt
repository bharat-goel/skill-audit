For a document dump like that, the fastest reliable path is a two-pass pipeline rather than one giant summarization prompt: **(1) bulk-extract text from every file** (PDF→text/OCR as needed, one file per output) **(2) fan out per-document summaries in parallel** (e.g. background subagents or batched Claude calls, each returns key facts/dates/names) **(3) one synthesis pass** that reads all the summaries together and drafts the report with cross-references. Single-pass "just summarize the whole tranche" is faster to set up but silently drops details and misses connections across documents once the tranche is more than a handful of files — the two-pass approach costs a bit more time/tokens but is far more trustworthy for anything you'd actually cite.
