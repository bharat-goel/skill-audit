Fastest path once release 02 lands in a folder:

```
scripts/run_all.py <release_root>
```

That chains inventory → text extraction → analytics → report in one call, writing `inventory.csv`, `text/`, `analytics/`, and `REPORT.md`. If the folder's big enough that a single call risks timing out in your sandbox, run the four steps individually instead so you can chunk the extraction step:

1. `scripts/inventory.py <release_root>`
2. `scripts/extract_text.py <release_root> [start] [end]` — slice into batches of ~25 files if any 45s-call limits apply
3. `scripts/analyze.py <release_root>`
4. `scripts/build_report.py <release_root>`

Two things worth doing on a *new* tranche specifically:
- Check `inventory.csv` for filename prefixes not covered in `references/agency_vocab.md` — anything landing in `OTHER` above ~3% means the vocab needs a quick extension before the report's agency breakdown is trustworthy.
- If `release_01/` is still sitting alongside it, mention you can diff the two reports for what's new — that's usually the next question once release 02's report is in hand.
