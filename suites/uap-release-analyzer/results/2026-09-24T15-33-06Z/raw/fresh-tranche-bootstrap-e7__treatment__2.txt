Fastest path once release 02 lands in a folder:

```
python3 scripts/run_all.py <path/to/release_02_root>
```

That runs inventory → text extraction → analytics → report in one shot, and writes `inventory.csv`, `text/`, `analytics/`, and a `REPORT.md` you can read end to end in ~10 minutes.

Two things worth doing before you kick it off:

1. **Layout matters** — put the actual PDFs in a subfolder (e.g. `release_02/release_02/`) matching the pattern the scripts expect, since inventory/analytics write siblings (`inventory.csv`, `text/`, `analytics/`) next to it.
2. **Check for new filename prefixes** — if release 02 introduces agencies/sources not in `references/agency_vocab.md` (currently FBI/DOW/NASA/DOS/NARA prefixes), the `OTHER` bucket in the report will flag them. If `OTHER` is more than ~3% of files, add the new prefix to `references/agency_vocab.md` and `PREFIX_RULES` in `scripts/inventory.py`/`scripts/analyze.py` before trusting the agency breakdown.

If your sandbox has a per-call timeout and extraction stalls on the big FBI batches, run `extract_text.py <root> <start> <end>` in chunks of ~25 instead of the full `run_all.py` — it's idempotent, so you can resume without redoing work.
