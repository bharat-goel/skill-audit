A generic recommendation: download into one folder, run everything through text extraction (`pdftotext`/OCR if scans) into a single corpus, then fan out — spawn a batch of parallel Explore or general-purpose subagents to each skim a chunk of the tranche and pull out key facts/entities into structured notes, and have one final pass synthesize those notes into the actual report (as a file or Artifact). That's the fast path because the extraction and skimming stages parallelize well; the tradeoff is that parallel skimming trades some depth for speed — cross-document connections and subtle details are more likely to get missed than if you read everything sequentially yourself.
