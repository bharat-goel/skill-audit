Fastest path once release_02 lands in a folder:

```
python3 scripts/run_all.py <path/to/release_02_root>
```

That chains all four pipeline steps — inventory → text extraction → analytics → report — and produces `REPORT.md` in the release root. On a tranche similar in size to the May PURSUE release (~2.5GB/4,000 pages), expect a few minutes; if you're running in a sandbox with per-call timeouts, use `extract_text.py <root> <start> <end>` in chunks of ~25 files instead of `run_all.py`, since that's the step that can blow a timeout.
