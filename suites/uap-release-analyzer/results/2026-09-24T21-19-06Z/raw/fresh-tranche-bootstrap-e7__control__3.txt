Fastest path: don't do it manually each time — build a small repeatable pipeline now so release 02 is just "run it." Concretely: (1) a script that ingests whatever the tranche contains (PDFs/CSVs/etc.) and normalizes it to text, (2) a Claude pass that extracts key facts/entities per document, (3) a synthesis pass that rolls those into a structured report (findings, notable items, open questions) written to a file or artifact. The main tradeoff is upfront cost — building and testing the pipeline against release 01's data now vs. just wading through release 02 by hand when it lands, which is slower per-release but requires zero setup.
