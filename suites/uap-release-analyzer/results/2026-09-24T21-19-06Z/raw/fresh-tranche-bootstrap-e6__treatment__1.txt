Once release 02 lands in a folder, run the bundled pipeline end-to-end:

```
python3 scripts/run_all.py <release_02_root>
```

That chains inventory → text extraction → analytics → report, and each step is idempotent, so if a large batch times out partway through, just re-run the same command and it picks up where it left off (extraction skips files that already have a `.txt`).

Two things worth doing before you kick it off:
1. **Check for new filename prefixes.** If release 02 introduces a new agency or source pattern, the `OTHER` bucket in the inventory will spike. Worth eyeballing `inventory.csv`'s agency column after step 1 — if `OTHER` is >~3%, add the new prefixes to `references/agency_vocab.md` and `PREFIX_RULES` before running analytics, otherwise those docs get lumped together uselessly.
2. **If you're pulling files from war.gov yourself** rather than starting from an already-downloaded folder, check `references/war_gov_quirks.md` first — the download links are hidden behind a modal and about a sixth of records are inline-viewer-only with no clean URL, so that part isn't a simple wget loop.

End result: `REPORT.md` in the release root, readable in ~10 minutes, plus `inventory.csv` and `analytics/*` if you want to dig into specifics.
