The fastest path is a repeatable pipeline rather than working through documents ad hoc each release: (1) a small script that pulls the new files and normalizes them (OCR any scanned PDFs, strip to plain text), (2) a fixed extraction prompt run per-document or per-batch that pulls out the same structured fields every time (dates, entities, claims, page refs), then (3) a synthesis pass that rolls those extractions into the report template you're already using. The main tradeoff: building that pipeline once costs you an hour or two now but makes each future release nearly instant; skipping it and just feeding files to Claude interactively is faster to start but you re-pay the setup cost every tranche and results are less consistent report-to-report.
