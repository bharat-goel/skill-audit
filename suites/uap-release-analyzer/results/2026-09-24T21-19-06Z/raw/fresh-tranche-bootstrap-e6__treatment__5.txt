Fastest path once release_02 lands in a folder:

1. Drop the PDFs into a `release_02/` directory (sibling to your `release_01/` if you still have it — that unlocks "what's new" comparisons for free).
2. Run `scripts/run_all.py <release_root>` — it chains inventory → text extraction → analytics → report in one shot. For a few-hundred-file tranche this is a few minutes, not hours.
3. Read `REPORT.md`. That's it — ten-minute read, standardized sections every time.

Two things worth doing *before* step 2 if you want a clean run:
- If any filenames use prefixes not in `references/agency_vocab.md` (new agency, new naming convention from war.gov), extend the vocab table + `PREFIX_RULES` in `inventory.py`/`analyze.py` first — otherwise they'll pile up in the `OTHER` bucket and skew section 1/5 of the report.
- Skip OCR by default. A big chunk of these releases are scanned images with no text layer; the pipeline correctly flags them as "OCR needed" in the missing-data section rather than silently dropping them. Only run OCR as an explicit follow-up if you actually need those pages' content.

If you pulled the files straight from the war.gov page rather than already having them locally, check `references/war_gov_quirks.md` first — the download flow there is fiddly (paginated DOM, modal-gated URLs, some records with no clean download link).
