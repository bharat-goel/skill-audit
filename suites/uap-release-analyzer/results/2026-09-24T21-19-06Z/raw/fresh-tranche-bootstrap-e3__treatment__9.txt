Once release 02 lands in a folder, run the bundled pipeline end-to-end:

```
python3 scripts/run_all.py <path_to_release_02_root>
```

That chains inventory → text extraction → analytics → report, and produces `REPORT.md` at the end. A few notes for when you actually do it:

1. **Point it at the right root.** The script expects a `release_root` containing the raw PDFs/images (e.g. `release_02/`), and it creates `text/`, `inventory.csv`, `analytics/`, and `REPORT.md` alongside it.
2. **It's idempotent** — if extraction times out partway (large FBI sections can be 200+ pages), just rerun `extract_text.py <root> [start] [end]` in chunks; already-extracted files are skipped.
3. **New filename prefixes will likely show up.** If `OTHER` in the inventory exceeds ~3%, check `references/agency_vocab.md` and add the new prefixes there plus `PREFIX_RULES` in `scripts/inventory.py`/`analyze.py` before trusting the agency breakdown.
4. **Don't wait on OCR.** Scanned files with no text layer are expected — the report flags them under "What's missing," and OCR is a separate follow-up, not part of the default path.
5. **If you have release_01 sitting alongside it**, mention that and I can add a quick release-to-release diff (new agencies, new locations, term deltas) on top of the standard report.

So practically: drop the files in a folder, tell me the path, and I run the four scripts — you get a `REPORT.md` in a few minutes, not something you need to babysit.
