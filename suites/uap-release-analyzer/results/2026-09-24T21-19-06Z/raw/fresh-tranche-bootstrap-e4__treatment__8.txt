Drop the new files under a `release_02/` folder and run `scripts/run_all.py release_02` — it chains inventory → text extraction → analytics → `REPORT.md` in one shot, and everything is idempotent/incremental so re-runs just fill gaps. The main tradeoff: `run_all.py` calls `extract_text.py` for the whole tranche at once, which can time out if this release has the same 200+ page FBI-style PDFs — if that happens, fall back to running the four scripts individually and chunk extraction with `extract_text.py release_02 <start> <end>`.

One thing worth doing before you trust the report: skim `inventory.csv`'s agency column for a big `OTHER` bucket, since a new release often ships filename prefixes not yet in `references/agency_vocab.md` — better to extend that vocab than find out later the analytics silently miscategorized a chunk of the tranche.
