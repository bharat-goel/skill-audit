Fastest path once release 02 lands in a folder:

```
scripts/run_all.py <release_root>
```

That chains all four pipeline steps (inventory → text extraction → analytics → report) in one shot, writing `inventory.csv`, `text/`, `analytics/`, and `REPORT.md`. If your sandbox has a per-call timeout, the extraction step may need chunking (`extract_text.py <release_root> start end` in batches of ~25 pages) rather than the single `run_all.py` call — the script is idempotent so re-running just picks up where it left off.

One thing to check before trusting the report: if new filename prefixes show up that aren't in `references/agency_vocab.md`, those files land in `OTHER`. If `OTHER` is more than ~3% of the tranche, add the new prefixes to the vocab table and `PREFIX_RULES` in `inventory.py`/`analyze.py` before reading the agency breakdown — otherwise the "Agency cross-references" section will be silently wrong.
