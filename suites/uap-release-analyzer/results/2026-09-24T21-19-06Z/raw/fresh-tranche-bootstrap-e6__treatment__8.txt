Fastest path once release 02 lands in a folder:

```
scripts/run_all.py <release_root>
```

That chains inventory → text extraction → analytics → report in one shot, writing `inventory.csv`, `text/*.txt`, `analytics/*`, and `REPORT.md` at the end — the same artifacts the standard workflow produces individually. If the sandbox you're running in has a per-call timeout and `extract_text.py` chokes on a big FBI section (200+ pages), drop back to running it directly in chunks (`extract_text.py <release_root> <start> <end>`) before continuing to `analyze.py` and `build_report.py` — everything is idempotent so resuming mid-pipeline is safe.

Two things worth doing at the start, not after:
- Check `inventory.csv`'s agency column once it's built — if `OTHER` is more than ~3% of files, release 02 probably introduced new filename prefixes. Add them to `references/agency_vocab.md` and the `PREFIX_RULES` in `inventory.py`/`analyze.py` before trusting the report's agency breakdown.
- Since you'll have `release_01/` sitting alongside it, that's a natural "what's new vs release 1?" comparison — worth asking for once both reports exist.

End state: a `REPORT.md` following the fixed 11-section structure, readable in ~10 minutes, with an honest "what's missing" section for anything unOCR'd or unextracted.
