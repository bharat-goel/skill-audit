Once release 02 lands in a folder, run the bundled pipeline end to end:

```
python3 scripts/run_all.py <path/to/release_02_root>
```

That chains inventory → text extraction → analytics → report, writing `inventory.csv`, `text/`, `analytics/`, and a final `REPORT.md` you can read in about ten minutes.

A couple of things worth knowing going in:

- **New filename prefixes will show up as `OTHER`.** If more than ~3% of files land in that bucket, it's worth pausing to add the new prefixes to `references/agency_vocab.md` and the `PREFIX_RULES` in `scripts/inventory.py`/`analyze.py` before trusting the agency breakdown — otherwise the report undercounts real buckets.
- **If you're pulling files live from war.gov/UFO/ rather than starting from an already-downloaded folder**, check `references/war_gov_quirks.md` first — there are known gotchas (paginated DOM, download links only appearing after a modal opens, some records with no clean URL, egress allowlist issues).
- **OCR isn't run automatically** — scanned PDFs with no text layer will show up as 0-char extractions and get flagged in the report's "What's missing" section rather than silently skipped.
- **If release_01/ is still in the parent folder**, that's a good opening for a release_01 vs release_02 comparison — worth asking if you want that framed in the report.

So: drop the tranche in a folder, run `run_all.py` against it, skim `REPORT.md`. That's the fast path.
