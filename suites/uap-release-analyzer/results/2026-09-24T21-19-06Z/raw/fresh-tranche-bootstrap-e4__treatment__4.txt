Fastest path once release 02 lands in a folder:

1. `python scripts/run_all.py <release_root>` — this chains inventory → text extraction → analytics → report in one shot, writing `inventory.csv`, `text/`, `analytics/`, and `REPORT.md`.
2. Read `REPORT.md`. That's it — ~10 minutes of runtime for a tranche the size of the May release, no manual steps in between.

Two things worth doing alongside that, not instead of it:

- **Check for new filename prefixes first** if you want a clean run: if release 02 introduces agencies/sources not in `references/agency_vocab.md`, files will pile into `OTHER`. Worth a quick `ls` scan of filenames before running `run_all.py` — if you spot unfamiliar prefixes, add them to the vocab table and `PREFIX_RULES` in `scripts/inventory.py`/`analyze.py` first so the report classifies correctly instead of redoing it after.
- **If your sandbox has a per-call timeout**, `run_all.py`'s extraction step could get cut off on very long FBI-style PDFs (200+ pages). If that happens, fall back to running `extract_text.py <release_root> <start> <end>` in chunks of ~25 pages — it's idempotent, so you can resume rather than restart.
