## What I can say from the code

**1. Trace exporter URL (change this now).** `WithEndpointURL("http://otel-gateway:4318")` has no path. `WithEndpointURL` treats the URL path as the full request path and does not append `/v1/traces`. The Collector expects `/v1/traces`, so the exporter may post to the wrong path. That would be a bug in v1.44.0 as well, unless the upgrade notes say the default changed. Making the path explicit is correct under either version:

```go
exporter, err := otlptracehttp.New(ctx,
    otlptracehttp.WithEndpointURL("http://otel-gateway:4318/v1/traces"),
)
```

Alternatively, use `WithEndpoint("otel-gateway:4318")` and `WithInsecure()`, which keep the default `/v1/traces` path.

**2. Log record.** The pattern `var rec log.Record`, `SetBody`, `AddAttributes`, `logger.Emit(ctx, rec)` is the standard API. I can't confirm that v0.21.0 changes any of it. Compile against v0.21.0 and check that `AddAttributes` and `log.String` still resolve.
