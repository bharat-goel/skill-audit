**What the code shows:**

1. **Trace endpoint.** The Collector expects `http://otel-gateway:4318/v1/traces`, but the exporter is given `WithEndpointURL("http://otel-gateway:4318")` with no path.
   - I recall that in earlier versions an empty path from `WithEndpointURL` could override the default `/v1/traces` rather than fall back to it. I'm not certain of that, and I don't know whether v1.45.0 changes it.
   - You can remove the ambiguity in either version by putting the full path in the URL:
     ```go
     exporter, err := otlptracehttp.New(ctx,
         otlptracehttp.WithEndpointURL("http://otel-gateway:4318/v1/traces"),
     )
     ```
   - Or use `WithEndpoint("otel-gateway:4318")`, `WithInsecure()` and `WithURLPath("/v1/traces")`.
