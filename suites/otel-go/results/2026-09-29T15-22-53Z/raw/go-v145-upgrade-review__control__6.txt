**Changes that are safe whichever way the release notes read**

1. **Trace exporter URL.** Put the full path in the endpoint URL, so the exporter doesn't depend on how a version handles a path-less URL:
   ```go
   exporter, err := otlptracehttp.New(ctx,
       otlptracehttp.WithEndpointURL("http://otel-gateway:4318/v1/traces"),
   )
   ```
   The Collector expects `/v1/traces`, and the current value stops at `:4318`. As far as I recall, `WithEndpointURL` uses the URL's path as given rather than appending the signal path. If so, the current code would post to `/` in v1.44.0 as well. I haven't confirmed that for either version, so check it.

2. **Version bump.** Move the core modules (`go.opentelemetry.io/otel`, `otel/sdk`, `otel/exporters/otlp/otlptrace/otlptracehttp`) to `v1.45.0`. Move `otel/log` and `otel/sdk/log` to `v0.21.0`. Keep all core modules on the same version and all log modules on the same version.

3. **Log record.** Compile against v0.21.0 and fix any errors. I can't confirm whether `log.Record`, `SetBody` and `AddAttributes` changed in that release. If the build fails on them, the release notes for `otel/log` v0.21.0 will say what replaces them.
